## 업로드용 문안

**제목**: 프로와 일반인 스윙, 진짜 차이는 '순서'였습니다 #골프 #골프스윙 #shorts

**설명**
```
프로와 일반인의 스윙을 같은 조건(정면 각도·허리 높이·동일 거리·동일 화각)에서 비교했습니다.
· 회전량: 어깨 92° / 골반 45° vs 어깨 76° / 골반 28°
· 다운스윙 순서: 골반 → 몸통 → 팔 → 클럽
· 임팩트 몸통 열림: 약 25° vs 약 8°
다음 편에서는 임팩트 순간 몸의 열림 각도를 더 자세히 분석합니다.
```

**해시태그**: #골프 #골프스윙 #스윙분석 #골프레슨 #비거리 #임팩트 #골프연습 #shorts

## 목소리·속도 바꾸기

`narration.json` 의 `voice.speed` 를 조절하면 전체 말 속도가 바뀝니다(1.0~1.25 권장, 현재 1.15).
더 느긋한 2분대 버전이 필요하면 `speed` 를 1.0 으로 내리고 각 씬의 `min` 을 올리면 됩니다.
직접 녹음한 음성을 쓰려면 `out/voice/<씬id>.mp3` 를 같은 이름으로 덮어쓰고
`npm run tts` 대신 `npm run build && npm run video && npm run audio` 를 실행하세요.
