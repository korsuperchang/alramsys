# 종목 추천 모델 (Stage 2: 멀티팩터 스코어링)

KOSPI / KOSDAQ / NASDAQ 중 시장을 선택하면 단기·중기·장기·종합 각 상위 5개 종목을 추천하는 정량 모델입니다.

## 실행 방법

```bash
# 의존성 설치
pip install -r requirements.txt

# 파이프라인 테스트 (합성 데이터, API 불필요)
python recommend.py --market KOSPI --demo

# 실제 데이터로 실행
export DART_API_KEY=발급받은키   # https://opendart.fss.or.kr 무료 발급 (한국 재무비율용)
python recommend.py --market KOSPI
python recommend.py --market KOSDAQ
python recommend.py --market NASDAQ

# 특정 기준일로 실행
python recommend.py --market KOSPI --as-of 2026-07-01
```

- `DART_API_KEY`가 없어도 실행은 됩니다 — ROE/부채비율/영업이익률(퀄리티 팩터)만 빠진 채
  나머지 팩터로 점수가 계산됩니다 (가중치 자동 재정규화).
- 첫 실행은 데이터 수집 때문에 오래 걸립니다 (KOSPI 전 종목 시세 순회 수십 분).
  수집 결과는 `.cache/`에 저장되어 **같은 기준일 재실행 시 즉시 로드**됩니다.
- 나스닥은 기본적으로 종목 리스트 앞 500개만 수집합니다 (`NasdaqAdapter(max_tickers=...)`
  로 조정, `None`이면 전 종목 — 매우 느림).

## 프로젝트 구조

```
stock_recommender/
├── config.py          # 호라이즌·팩터·가중치·유니버스 필터 (튜닝은 여기서)
├── recommend.py       # 메인 실행 스크립트
├── factors.py         # 기술적 팩터 계산 (모멘텀, RSI, 거래량 급증)
├── scoring.py         # 스코어링 엔진 (정규화 → 카테고리 → 호라이즌 점수)
├── backtest.py        # Walk-forward 백테스트 골격
├── cache.py           # 수집 데이터 로컬 캐시 (.cache/)
├── dart.py            # DART Open API 연동 (재무비율, 공시기한 기준)
├── demo_data.py       # 합성 데이터 어댑터 (테스트용)
└── adapters/
    ├── base.py        # MarketAdapter 인터페이스
    ├── korea.py       # pykrx 기반 (KOSPI/KOSDAQ) + DART + 공매도
    └── nasdaq.py      # yfinance 기반 + 공매도 잔고 변화
```

## 모델 설계 요약

- **문제 정의**: 시장 내 횡단면 랭킹 (절대수익 예측이 아닌 상대비교)
- **정규화**: 시장별 percentile rank + 상하위 1% winsorize
- **호라이즌별 가중치**: 단기=모멘텀·수급 중심 / 장기=가치·퀄리티 중심
- **결측 처리**: 없는 팩터는 제외 후 가중치 재정규화 (나스닥의 수급 데이터 부재 등)
- **유니버스 필터**: 시총·거래대금 하한으로 거래 불가능 종목 배제

## 데이터 연동 상세

| 항목 | 방식 | 시점 정합성 처리 |
|---|---|---|
| 한국 시세/시총/PER/PBR | pykrx | 기준일 시점 데이터 |
| 한국 재무비율 (ROE 등) | DART `fnlttMultiAcnt` | **법정 제출기한이 지난 보고서만 사용** (사업보고서 3/31, Q1 5/15, 반기 8/14, Q3 11/14). 실제 공시일보다 보수적 → lookahead 없음 |
| 한국 공매도 | pykrx 일별 공매도 비중 | 최근 5일 평균 − 직전 20일 평균. **금지 구간은 자동 NaN** (조회 실패 시 팩터 무효화) |
| 한국 수급 | pykrx 외국인/기관 20일 순매수 | 기준일 시점 데이터 |
| 나스닥 시세 | yfinance 배치 다운로드 | 수정주가 기준 |
| 나스닥 재무/공매도 잔고 | yfinance `.info` | 공매도 변화는 **이전 실행 스냅샷과의 차분** (최초 실행 시 NaN, 2회차부터 유효) |

## 남은 한계 (알고 쓸 것)

| 항목 | 내용 |
|---|---|
| 생존편향 | pykrx/yfinance 종목 리스트는 현재 상장 종목 기준 → 백테스트 수익률 과대평가 가능 |
| 나스닥 재무 시점 | yfinance `.info`는 현재값만 제공 → 과거 시점 백테스트에는 EDGAR 등 이력 데이터 필요 |
| 백테스트 스냅샷 이력 | `backtest.py`는 골격 — 과거 각 시점의 스냅샷 복원(DART 공시일 기준)이 필요 |
| 나스닥 유니버스 | max_tickers 제한 시 알파벳순 앞부분만 수집됨 (시총순 아님) |

## 검증 시 주의사항 (필독)

1. **가중치를 백테스트로 튜닝할 때**: 튜닝 기간과 최종 평가 기간을 반드시 분리하세요.
2. **거래비용**: `backtest.py`의 비용 상수는 현재 세율·수수료 기준으로 갱신 후 사용하세요.
3. **백테스트 반복 횟수 기록**: 전략을 수정하며 백테스트를 반복할수록 우연에 적합될 위험이 커집니다.
