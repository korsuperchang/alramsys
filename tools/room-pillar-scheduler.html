모델 가정

  • 가상 자료. 숨은 '참' 광체(주향 N30°E, 남동 16° 경사, 두께 40~75m 석회석층, 상·하반 셰일)에서 시추 42공을 3m 구간으로 뽑았습니다. 남동부에 백운석화(MgO↑) 구역, 서부 층 중간에 셰일 협재(SiO₂↑)를 넣었습니다. 화면의 광체는 '참' 모델이 아니라 시추공으로 추정한 결과입니다.
  • 광체 추정. 시추공마다 CaO 40% 이상 구간으로 상·하반 경계를 읽고, 하반면 = 평면 추세 + 역거리 잔차, 두께 = 역거리 보간. 품위는 층 안 상대 위치(하반 0 ~ 상반 1)가 같은 시료끼리 역거리 가중(최대 8공, 450m).
  • 희석. 채굴고 중 층 밖으로 나간 부분은 셰일(CaO 6, MgO 2.4, SiO₂ 56)로 섞어 품위를 다시 계산합니다. 층 안 비율이 50% 미만이면 판넬을 만들지 않습니다.
  • 판넬 = 필러 1개 + 둘레 갱도. 필러 간격이 격자, 모든 편이 같은 격자를 써서 상·하 필러가 수직으로 겹칩니다. 판넬 톤 = (간격² − 필러²) × 채굴고 × 비중.
  • 필러 안전율. 하중 = 지류면적법 σp = ρgh × 간격²/필러². 강도 = 규모효과계수 × UCS × (0.778 + 0.222 × 필러폭/채굴고) (Obert–Duvall). 깊이 h는 판넬 중심의 지표에서 채굴고 중간까지.
  • 주운반 갱도 = 연층 사갱. 시추공으로 추정한 하반면 추세에서 층 자세(주향·경사)를 구하고, 하반면 아래 「하반 이격」만큼 떨어져 층과 나란히 내려가는 직선 사갱을 광체 무게중심에 맞춰 놓습니다. 사갱 경사가 층 경사보다 완만하면 tan(사갱) = tan(층) × cos(튼 각)이 되도록 경사 방향에서 주향 쪽으로 틉니다(겉보기 경사). 갱구는 사갱을 경사 위로 연장해 지표와 만나는 곳입니다.
  • 편 갱도. 사갱이 각 편 표고를 지나는 지점에서 주향 방향으로 냅니다(평면도 파란 선). 사갱 막장이 그 표고를 지나면 편이 열리고, 「편 개발 선행」 개월 뒤 채굴을 시작합니다. 사갱 양쪽 「보호 폭」 안, 사갱 바로 위 판넬은 보호 광주로 남깁니다.
  • 운반 방식별 경사 한계(일반값, 가정): 벨트 컨베이어 16°, 궤도 권양 25°, 트럭 8°. 입력 경사가 한계나 층 경사를 넘으면 줄여서 계산하고 경고를 띄웁니다.
  • 채굴 순서. 편은 하향식(위→아래) 또는 상향식, 동시에 N개 편. 편 안에서는 사갱·편 갱도 교차점에서 가까운 판넬부터(전진식). 매달 목표량을 순서대로 편당 상한까지 배분.
  • 한계. 수직공만 가정, 블록 모델·변동성 분석 없음, 필러 회수(후퇴 채굴)·충전·환기·배수 미반영. 단가는 모두 가정값이라 슬라이더로 바꿔 보는 용도입니다.
